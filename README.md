# skills

Agent skills by [@lorenzolfm](https://github.com/lorenzolfm). Install with the
[`skills`](https://skills.sh) CLI:

```sh
npx skills add lorenzolfm/skills --skill make-illegal-states-unrepresentable
```

## Skills

| Skill | Description |
| --- | --- |
| [make-illegal-states-unrepresentable](skills/make-illegal-states-unrepresentable/SKILL.md) | Examine a part of an existing program, find the illegal states the code can represent, and propose changes in four layers: the store, the access layer, the types and the boundary. |
